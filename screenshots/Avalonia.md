# Lemon Rind - Avalonia edition screenshots

The cross-platform desktop app (C# / Avalonia) - the same features as the WPF edition, running natively on Windows, Linux and macOS. Light theme throughout, plus one dark-mode view. Other editions: [WPF](WPF.md) | [Blazor](Blazor.md) | [back to the README](../README.md)

*The screenshots use sample data (a few made-up chats, memories, a knowledge base and a scheduled job) and a real reply from a local model.*
